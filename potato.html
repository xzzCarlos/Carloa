04 / INSTALACIÓN

Empieza en cuatro pasos.

Instala el mod manualmente en tu perfil de Fabric.

01

Instala Fabric

Descarga Fabric Loader y selecciona Minecraft 1.20.1 o 1.21.4.

02

Descarga el archivo

Obtén el archivo .jar de Potato Client desde el enlace oficial del proyecto.

03

Mueve el archivo

Coloca Potato Client y Fabric API dentro de la carpeta .minecraft/mods.

04

Abre Minecraft

Inicia el perfil de Fabric correspondiente y disfruta tu configuración.

05 / SOPORTE

Preguntas frecuentes.

Respuestas rápidas sobre Potato Client.

¿Potato Client es gratis?

Sí. El proyecto se presenta como gratuito.

¿Qué versiones son compatibles?

La información actual del proyecto indica Minecraft Java 1.20.1 y 1.21.4 con Fabric.

¿Necesito Fabric API?

Sí. Instala Fabric Loader y Fabric API de la misma versión que tu Minecraft.

¿Puedo usar otros mods?

La compatibilidad puede variar según los mods instalados. Consulta los canales de soporte del proyecto si encuentras algún conflicto.

¿Dónde consigo ayuda?

Únete a la comunidad de Potato Client cuando el enlace oficial de Discord esté configurado.
